# Corpus sintético de la issue #41

`issue41_synthetic.json` contiene tres textos originales ficticios de prevención de estafas, repetidos para ejercitar el chunking. No son publicaciones de INCIBE, OSI ni Banco de España; los identificadores de fuente solo prueban el esquema. Las URLs `example.invalid` no se visitan ni se muestran como evidencias oficiales. El pipeline los mide con E5 y los almacena en una base aislada de demostración. Nunca mezclar con el corpus real ni usar como benchmark de precisión.
